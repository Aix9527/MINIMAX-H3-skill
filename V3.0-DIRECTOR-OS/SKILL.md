# MiniMax H3 Director OS v3.0.0-alpha

## Pipeline

Story Input
-> Story Analyzer
-> Director Brain
-> Case Memory
-> Shot Planner
-> Prompt Compiler
-> Quality Gate
-> director.json

## Core Rules

1. One shot one dominant action.
2. Camera movement must be explicit.
3. Audio design is part of generation.
4. Lighting and color establish visual identity.
5. Reference images lock identity.
6. Ending frame must be defined.
7. Dialogue scenes require speaker ownership.

## Reliability System

- Speaker Swap prevention
- Scene Drift prevention
- Identity Drift prevention
- Motion Collapse prevention
