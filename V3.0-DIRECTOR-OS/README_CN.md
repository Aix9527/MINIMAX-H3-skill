# MiniMax H3 Director OS v3.0.0-alpha

## 中文说明

MiniMax H3 Director OS 是面向 MiniMax H3 视频生成的 AI 导演提示词系统升级版本。

核心能力：

- Director Brain AI导演决策
- Story Analyzer 剧情分析
- Case Memory 案例驱动
- Shot Planner 自动拆镜
- Prompt Compiler 提示词编译
- Quality Gate 质量检测
- Speaker Ownership 对白角色控制
- Continuity Memory 场景连续性管理
