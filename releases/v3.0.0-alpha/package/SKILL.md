# MiniMax H3 Director OS Skill v3.0.0-alpha

## Purpose

AI video director skill for MiniMax H3.

## Workflow

Story Analysis -> Director Brain -> Shot Planning -> Prompt Compilation -> Quality Validation

## Core Rules

1. One prompt = one primary action.
2. Camera movement must be explicit.
3. Audio and environment details should be specified.
4. Character identity belongs to reference images.
5. Prompt controls action, camera and cinematic execution.
6. Maintain scene continuity.
7. Define ending frame.

## Output

Generate structured H3 video prompts and director.json specifications.
