# MiniMax H3 Director OS v3.0.0-alpha

## 中文说明

MiniMax H3 Director OS v3.0.0-alpha 是全新的 AI 视频导演提示词系统架构。

核心升级：

- AI Director 决策层
- Story Analyzer 剧情分析
- Director Brain 导演规划
- Case Memory 案例记忆
- Shot Planner 自动拆镜
- Prompt Compiler 提示词编译
- Quality Gate 质量检查
- Failure Recovery 失败恢复
- director.json V5 结构化输出

## English

MiniMax H3 Director OS v3.0.0-alpha introduces an AI Director architecture for MiniMax H3 video generation workflows.

Features:

- Story Analyzer
- Director Brain
- Case Memory Engine
- Shot Planner
- Prompt Compiler
- Quality Gate
- Failure Recovery System
- director.json V5 specification

## Migration

V2.x prompt workflows remain compatible through migration rules. V3.0 introduces structured director decisions and shot-based generation.

## Status

Alpha release. Production workflows should be validated with project-specific tests before final deployment.
